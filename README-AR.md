# تطبيق متابعة العبادات والأخلاق

مشروع جاهز لبناء APK عبر GitHub Actions.

## الاستخدام من الموبايل
1. ارفع محتويات هذا المجلد إلى مستودع GitHub باسم `ebada-app` (ارفع الملفات والمجلدات الموجودة داخل ZIP، وليس ملف ZIP نفسه).
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Android APK** ثم **Run workflow** إذا لم يبدأ البناء تلقائيًا.
4. بعد اكتمال البناء افتح نتيجة التشغيل، وانزل إلى **Artifacts**، ثم نزّل `ebada-app-debug-apk`.
5. فك ضغط الملف الذي تم تنزيله وستجد `app-debug.apk` لتثبيته على هاتف Android.

هذا APK تجريبي للتثبيت الشخصي، وليس نسخة متجر Google Play. بيانات المتابعة محفوظة محليًا على الجهاز.
